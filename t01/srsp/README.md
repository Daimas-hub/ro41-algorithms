# t01 — Перевод секунд в часы, минуты и секунды

Файлы:

- `algorithm.md` — словесная запись и псевдокод
- `scheme.png` — схема алгоритма по ГОСТ 19.701-90 (исходник: `scheme.drawio`)
- `Program.cs` — консольная программа на C#

Запуск: `dotnet run`

## Проверка

| Ввод  | Результат                     |
|-------|-------------------------------|
| 3725  | 3725 с = 1 ч 2 мин 5 с        |
| 59    | 59 с = 0 ч 0 мин 59 с         |
| 86399 | 86399 с = 23 ч 59 мин 59 с    |
| 0     | 0 с = 0 ч 0 мин 0 с           |

Некорректный ввод:

| Ввод | Результат                                              |
|------|--------------------------------------------------------|
| abc  | Ошибка: нужно ввести целое число, например 3725.       |
| -5   | Ошибка: число секунд не может быть отрицательным.      |
